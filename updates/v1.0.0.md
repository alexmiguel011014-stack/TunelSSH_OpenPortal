# v1.0.0 — OpenPortal Remote (Instalador + Auto-update)

**Data:** 2026-07-30

## O que foi implementado

- Proxy VNC (WebSocket <-> TCP, porta 18900)
- Proxy File Transfer (WebSocket <-> TCP, porta 18901)
- File Server embutido (TCP, porta 5001) — agente receptor
- Dashboard com status do servidor local
- Sidebar recolhivel com lista de PCs (ate 20 maquinas)
- Remote Viewer VNC (noVNC em iframe isolado)
- File Transfer two-panel (AnyDesk style) com upload de pastas
- Auto-update via GitHub Releases (electron-updater)
- Regra de firewall no instalador (porta 5001)

## Como usar

1. Baixe o instalador em: https://github.com/alexmiguel011014-stack/TunelSSH_OpenPortal/releases/tag/v1.0.0
2. Execute `OpenPortal Remote Setup 1.0.0.exe` — nao precisa de Node.js
3. O app inicia com file server embutido na porta 5001

## SmartScreen / Certificado

O instalador e assinado com certificado auto-assinado. Para o SmartScreen nao bloquear:

1. Copie `resources/cert.cer` para o PC alvo
2. Execute o .cer e escolha **"Instalar Certificado"**
3. Em "Local de armazenamento", escolha **"Maquina Local"**
4. Em "Repositorio", escolha **"Trusted Root Certification Authorities"**
5. Pronto — o SmartScreen confia no instalador
